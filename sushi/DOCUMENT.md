## 1. 产品愿景

### 1.1 一句话定位
**"素时"是中国个人用户的离线时间账本 — 帮你看见自己,不做你的主人。**

### 1.2 北极星指标
**不是 DAU、不是留存,而是"用户一生累计记录的有效时间数"。**
- 这是一个慢指标,也是最诚实的指标。
- 如果有人用素时记了 5 年、记了 3 万小时,这款 App 就成功了。

### 1.3 核心价值观(五条铁律)
1. **不上传** — 没有任何网络请求能带用户数据出门
2. **不打扰** — 不推送、不弹窗、不横幅、不红点
3. **不评判** — 不打分、不排名、不"今日最佳"
4. **不锁定** — 一键导出,一键清空
5. **不变化** — 核心功能写完就封版,只修 bug 不加戏

### 1.4 产品隐喻
- ❌ 不是"工具" → 是"账本"
- ❌ 不是"App" → 是"私人日记本"
- ❌ 不是"服务" → 是"数字文物"

## 2. 目标用户与场景

### 2.1 核心用户画像
**小明 / 28 岁 / 北京 / 互联网产品经理**

- 每天加班到 10 点,偶尔想"我这一天都干了啥"
- 用过 Forest、滴答清单、番茄 ToDo,都觉得"太累"
- 不喜欢被推送打断,但又想有点"自我管理"意识
- 反感内卷话术("自律改变人生")
- 用国产 Android 手机,装了一堆工作 App,想要个"清净角落"
- 对隐私敏感,不想让任何 App 知道他的作息

### 2.2 次要用户
| 画像 | 场景 |
|---|---|
| 大学生(20-25) | 想"看见"自己的时间花在哪,是学习还是刷剧 |
| 自由职业者(30-45) | 需要事后记录,方便给客户开发票、对账 |
| 退休人士(55-70) | 想给晚年留一份"时间日记",无需复杂功能 |
| 文字工作者(25-40) | 写作者、编辑,需要追踪"有效工作时间" |

### 2.3 典型使用场景
- **晨间**: 打开 App,看到昨天时间分布,决定今天多陪家人
- **工作中**: 客户电话来了,临时记录 15 分钟"会议"
- **下班后**: 地铁上滑一眼,看今天 8 小时都做了什么
- **周末**: 翻看本周时间饼图,做一次"复盘"
- **年底**: 导出一份 PDF,打印放在抽屉里,作为"今年的时间"

## 3. 功能规划

### 3.1 核心功能(MVP,V1.0 必做)

#### 3.1.1 时间记录
- **开始**: 单击主按钮 → 进入"记录中"状态
- **暂停**: 单击 → 暂停计时,显示已用时长
- **继续**: 单击 → 继续计时
- **结束**: 长按 → 弹出"完成"确认 → 输入分类与备注 → 保存
- **手动添加**: 历史记录页可补录(用于"忘了开"的场景)

#### 3.1.2 分类体系
- 8 大生活域(预置、不可删、可隐藏):
  1. **工作** — 谋生类活动
  2. **学习** — 求知类活动
  3. **家庭** — 陪伴/赡养/育儿
  4. **健康** — 运动/饮食/睡眠
  5. **爱好** — 兴趣/创作
  6. **社交** — 亲友/人情
  7. **休息** — 娱乐/放空
  8. **修行** — 阅读/冥想/反思
- 每个分类支持**二级标签**(用户自定义,最多 20 个)
- 颜色由 8 大域决定(每域一色),二级标签不染色

#### 3.1.3 历史记录
- **日历视图**: 月历,每天显示总时长(色块深浅 = 时长)
- **列表视图**: 当日所有记录的时间轴
- **筛选**: 按分类、按时间(今日/本周/本月/本年/全部)

#### 3.1.4 数据统计
- **日**: 当日分类饼图
- **周**: 本周分类柱状图 + 与上周对比
- **月**: 本月分类饼图 + 24 节气标注
- **年**: 本年热力图(365 天)

#### 3.1.5 本地备份与恢复
- **导出**: 一键导出 JSON 文件到手机本地存储
- **导入**: 选择 JSON 文件导入(覆盖/合并两种模式)
- **格式公开**: JSON 格式文档化,用户可用任何文本编辑器查看

#### 3.1.6 设置
极简,只有 6 项:
- 主题模式(浅色/深色/跟随系统)
- 默认分类
- 24 节气提示(开/关)
- 数据导出
- 数据清空
- 关于

### 3.2 扩展功能(V1.1 选做)

| 优先级 | 功能 | 说明 |
|---|---|---|
| 高 | 24 节气提示 | 启动时根据当日节气显示一句古语 |
| 高 | 农历日期 | 日历显示农历,符合中国习惯 |
| 高 | 法定节假日 | 内置 2025-2030 节假日数据 |
| 中 | 每日复盘 | 一日结束后输入"今日无憾之事" |
| 中 | 心情标签 | 5 级:平静/愉悦/焦虑/疲惫/痛苦 |
| 中 | 目标设定 | "本月读书 20 小时"类目标 |
| 中 | PDF 年度报告 | 一年结束导出一本"时间之书" |
| 低 | 多主题 | 素白/墨黑/宋青/落柿 4 套 |
| 低 | 锁屏小组件 | 显示今日累计时长 |

### 3.3 不做清单(明确排除)

| 不做 | 原因 |
|---|---|
| AI 智能分析 | 用户应自己思考,不让算法代劳 |
| 云同步/账号系统 | 违背"不联网"承诺 |
| 社交分享 | 时间是私人的,不该是社交货币 |
| 游戏化(经验/等级) | 不是 RPG,不做"打怪升级" |
| 番茄钟/强提醒 | 不打扰铁律 |
| 推送通知 | 不打扰铁律 |
| 会员/内购/广告 | 纯公益承诺 |
| 第三方登录 | 无需登录 |
| 崩溃/统计 SDK | 无需上报 |
| 国际化多语言 | 先做透中文用户 |

## 5. 美学规范

### 5.1 设计哲学
**宋式极简 + 现代数字界面**
- 留白即美
- 一字不多
- 静比动好
- 装饰皆多余

### 5.2 色彩系统

| 茶褐 | `#8B7355` | 辅助文字、分割线 |

### 5.3 字体系统

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 大标题(当前时长) | 思源宋体 | 56sp | Heavy |
| 中标题(页面) | 思源宋体 | 24sp | Bold |
| 正文 | 思源黑体 | 16sp | Regular |
| 辅助文字 | 思源黑体 | 14sp | Light |
| 数字(计时) | Roboto Mono | 48sp | Medium |
| 古语引言 | 方正楷体 | 18sp | Regular |
| 标签 | 思源黑体 | 12sp | Medium |

**字间距**: 标题 -0.02em,正文 0,辅助 +0.02em
**行高**: 1.6(正文)/ 1.2(标题)

### 5.4 间距与栅格
**8 进制**:`4 / 8 / 16 / 24 / 32 / 48 / 64 / 96`
- 卡片内边距: 16
- 卡片间距: 16
- 页面边距: 24
- 大区块间距: 48

### 5.5 圆角与阴影
- **圆角**: 极小 — 按钮 2px / 卡片 8px / 模态框 12px
- **阴影**: 几乎不用,改用 1px `#E8E4D9` 描边
- **例外**: 浮动按钮(主按钮)用 4dp 阴影,符合 Material 习惯

### 5.6 图标系统
- 风格: **细线图标** (line icon),1.5px 描边
- 来源: **Lucide Icons**(开源 MIT,无需联网下载)
- 尺寸: 24dp(标准) / 16dp(辅助) / 32dp(大图标)
- 颜色: 跟随文字色

### 5.7 动效
- **原则**: 慢、少、有意义
- **时长**: 300-500ms
- **曲线**: `FastOutSlowInEasing`(进入) / `LinearOutSlowInEasing`(退出)
- **类型**:
  - 页面切换: 横向滑动 300ms
  - 模态框: 自下而上 400ms
  - 按钮反馈: 缩放 95% + 50ms 回弹
  - 计时器数字变化: 翻牌效果 200ms
- **不做**: 粒子效果、过场动画、Loading 旋转、骨架屏

### 5.8 插画
- 风格: **极简线稿水墨**
- 用途: 空状态、关于页、关于节气
- 来源: 全部为开源插画(unsplash.com 许可),内置 APK
- 数量: 控制在 10 张以内

## 6. 交互规范

### 6.1 核心手势
| 手势 | 触发 | 效果 |
|---|---|---|
| 单击大按钮 | 主页中央 | 开始/暂停 |
| 长按大按钮 1.5s | 主页中央 | 结束并保存 |
| 左滑主页 | 主页 | 进入历史 |
| 右滑主页 | 主页 | 进入统计 |
| 双击大按钮 | 主页中央 | 快速复盘 |
| 下拉 | 列表页 | 刷新(实际为本地重算) |
| 长按记录 | 列表项 | 编辑/删除弹窗 |

### 6.2 反馈机制
- **视觉**: 任何点击都有色彩/形状变化(50ms)
- **触觉**: 主操作触发震动(`HapticFeedback.LongPress`,50ms)
- **声音**: ❌ 不使用任何声音
- **微动效**: 数字翻牌、按钮呼吸、计时器脉冲

### 6.3 错误处理
**核心原则**: 不弹错误,直接做事。
- 数据保存失败: 静默重试 3 次,失败则写入"待恢复队列",启动时再试
- 输入非法: 实时红色提示 + 阻止保存
- 操作冲突(同时保存): 后保存者覆盖前保存者,提示用户
- **绝不弹** "网络错误" "未知异常" "请稍后重试" 这种空话

### 6.4 空状态
每个列表/页面都要有"无内容"状态,文案遵循"零评判"原则:
- ❌ "您还没有记录,快开始吧!"(带感叹号,带催促)
- ✅ "此刻,还无记录。"(平静,无引导)
- ❌ "今日完成度 0%"(带评判)
- ✅ "今日"(只陈述)

### 6.5 无障碍
- 所有图标加 `contentDescription`
- 字号支持系统级缩放(SP 单位)
- 颜色对比度 ≥ 4.5:1(深色主题同样满足)
- TalkBack 焦点顺序与视觉一致
- 主按钮可被焦点切换

### 6.6 输入法适配
- 备注输入支持中文拼音、九键、双拼
- 自动联想关闭(尊重隐私)
- 弹起输入法时,主按钮固定在屏幕底部

## 9. 反功能清单(Anti-features)

> 这是素时最独特的地方 — **明确承诺不做的事**。

| 反功能 | 用户得到的价值 |
|---|---|
| ❌ 无账号 | 无需注册,打开即用 |
| ❌ 无云同步 | 数据物理上无法泄露 |
| ❌ 无 AI 分析 | 自己思考,不被算法代劳 |
| ❌ 无推送通知 | 不被 App 打断 |
