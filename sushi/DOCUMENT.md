## 1. 产品愿景

### 1.1 一句话定位
**"素时"是用时间养技能的中国个人成长记录器。**

- **时间是肥料**,**技能是树**
- 你记录的不是"我今天工作 8 小时",而是"我的'写作'技能今天长了 3 经验"
- 长期下来,看见自己**一棵一棵技能树在长**

### 1.2 核心模型(重申)
```
[时间记录] → [经验累积] → [技能等级] → [看见成长]
   输入          转化          输出          反馈
```

**柳比歇夫"纯时间"原理**:
- 1 分钟专注的有效时间 = 1 点纯时间 = 1 点技能经验
- **不看强度、不看状态,只看时间**
- 这是素时一切设计的根基,**所有功能围绕这个公式展开**

### 1.3 五条铁律(基于"免费/无 AI/不联网/纯公益"约束)
1. **不上传** — 我们没有自己的服务器,数据物理上无法被收集
2. **不打扰** — 不推送、不红点、不横幅
3. **不评判** — 不打分、不排名、不"今日最佳"
4. **不锁定** — 一键导出,一键清空
5. **不变化** — 核心机制写完就封版,只修 bug 不加戏

> **关于"不联网"**:
> 严格说,App 本身**不主动联网**。但提供**可选的坚果云 WebDAV 同步**,由用户主动配置、同步到用户自己的坚果云账号。
> 这与"无服务器"承诺一致 — 数据只存在用户自己的设备和用户自己的坚果云,**不经任何第三方**(包括我们)。
> WebDAV 同步默认关闭,需要在"我的 → 同步"中手动开启。

### 1.4 核心隐喻(不可动摇)
| 比喻 | 含义 |
|---|---|
| 技能树 | 你的人生是若干棵树的集合 |
| 经验值 | 时间是浇树的肥料 |
| 等级 | 树的高度(1-9 生苗 / 10-29 青铜 / 30-99 红金 / 100+ 玄铁) |
| 毕业 | 100 级以上的技能可以"毕业",进入大师之列 |
| 连续记录(Streak) | 连续多日没断过浇水 |
| 技能分布 | 你这片森林的生态 |

**这些隐喻不可取消,这是素时的灵魂。**

## 2. 目标用户与场景

### 2.1 核心用户画像
**小芸 / 26 岁 / 杭州 / 自由插画师**

- 副业学 Python 编程,正职画画,想看见"自己到底在学什么"
- 用过 Forest(觉得太游戏化)、滴答清单(觉得是任务工具不是技能)
- 想要一款"为成长而记"而非"为效率而做"的 App
- 用国产 Android,反感推送,对隐私敏感
- 偶尔在 B 站/小红书发学习记录,会手动截图,不需要 App 分享

### 2.2 次要用户
| 画像 | 场景 |
|---|---|
| 大学生 | 想量化自己的"学习投入"是否真的有积累 |
| 程序员 | 副业学新语言,想看见"30 天连续学习"的效果 |
| 写作者 | 想长期跟踪"写作"技能的成长曲线 |
| 父母 | 培养孩子某项兴趣(如钢琴、阅读),需要长期记录 |
| 退休人士 | 老年大学学书法/太极,想看见自己每天的进步 |

### 2.3 典型使用场景
- **晨起**: 打开素时,看到"昨天写作长了 80 经验"很开心
- **工作中**: 切换到"阅读"技能开始计时
- **学习时**: 给"Python"技能开 45 分钟番茄式专注
- **晚间**: 翻看今日热力图,所有格子都亮了,感到充实
- **月底**: 查看"写作"技能月报,发现本月从青铜升到红金
- **年底**: 查看"Python"技能年度热力图,看见 365 天里 200 天有记录
- **某技能 100 级**: 系统提示"是否毕业",可写入毕业感言
- **持续记录 30 天**: Streak 加冕,获得"持之以恒"成就徽章

## 4. 信息架构

### 4.1 底部导航(Google Material 3 风格)
**5 个 Tab,无侧边栏、无抽屉**(对标 Google Fit / Google Tasks 的极简导航)

```
┌────────────────────────────────┐
│        主内容区(随 Tab 切换)        │
├────────────────────────────────┤
│ 🏠  📈  🌱  📊  ⚙️  │  [+]  │
│ 主页 技能 目标 报告 我的 │  记录  │
└────────────────────────────────┘
```

| Tab | 入口 | 核心内容 |
|---|---|---|
| 🏠 **主页** | 默认 | 当前技能、今日累计、最近记录 |
| 📈 **技能** | 第二项 | 技能列表、技能分布饼图 |
| 🌱 **目标** | 第三项 | 周/月目标、连续记录 |
| 📊 **报告** | 第四项 | 日/周/月/年 4 个时间维度 |
| ⚙️ **我的** | 第五项 | 设置、备份、帮助、关于 |
| **[+]** | FAB | 快速开始记录(任何 Tab 都能调起) |

### 4.2 二级页面(从 Tab 内入口进)
- 主页 → 技能详情页(点击技能)
- 主页 → 复盘页
- 主页 → 24 节气详情
- 技能 → 技能树视图
- 技能 → 成就墙
- 技能 → 任务管理
- 目标 → 周目标详情
- 报告 → 月度 PDF 导出
- 我的 → 设置
- 我的 → 帮助中心
- 我的 → 关于

### 4.3 模态与浮层
- **快速开始** → ModalBottomSheet(从 FAB 触发)
- **技能选择** → ModalBottomSheet
- **复盘输入** → FullScreenDialog(避免误触)
- **成就解锁** → Snackbar(简短提示)
- **升级庆祝** → FullScreenOverlay(2 秒后自动消失)

## 5. 美学规范(Google Material 3 + 中国气质)

### 5.1 设计哲学(双线融合)
| Google 理念 | 中国气质 |
|---|---|
| Material 3 动态 | 静水深流 |
| Surface elevation | 墨色层次 |
| Generous spacing | 留白为美 |
| Rounded corners | 不必方正 |
| Functional motion | 不必炫技 |
| Clear typography | 字体端正 |
| Honest UI | 不装饰 |

**原则**: 用 Google 的**设计骨架**(Material 3),用中国的**视觉血肉**(配色、文案、字体)。

### 5.3 字体系统

| 用途 | 字体 | 字号 | 字重 | 备注 |
|---|---|---|---|---|
| 大数字(计时) | **Roboto Mono** | 56sp | Medium | 数字等宽 |
| 页面大标题 | 思源黑体 | 28sp | Bold | |
| 卡片标题 | 思源黑体 | 18sp | Medium | |
| 正文 | 思源黑体 | 16sp | Regular | |
| 辅助文字 | 思源黑体 | 14sp | Regular | |
| 标签/数据 | 思源黑体 | 12sp | Medium | 全大写 + 字间距 |
| 古语引言 | 霞鹜文楷 | 18sp | Regular | 中国书法美感 |
| 英文混排 | Google Sans Text | 同级 | 同级 | 自动混排 |

**字间距**: 标题 -0.01em / 正文 0 / 辅助 +0.02em
**行高**: 1.5(正文)/ 1.2(标题)/ 1.0(数字)

### 5.4 间距与栅格
**Material 3 标准 4dp 基准**:
- 极小: 4dp
- 小: 8dp
- 中: 16dp
- 大: 24dp
- 极大: 32dp
- 区块: 48dp
- 页面边距: 16dp(手机)/ 24dp(平板)

### 5.5 圆角与形状
- **小元素**(按钮、标签): 8dp
- **卡片**: 12dp
- **大卡片/模态**: 16dp
- **FAB**: Material 3 标准 16dp
- **不使用异形**(波浪、斜切)

### 5.6 阴影与 elevation
- **不用传统阴影**,改用 **Material 3 surface tint**:
  - level 0: 0 elevation,纯色
  - level 1: 1dp + 1% tint
  - level 2: 3dp + 3% tint
  - level 3: 6dp + 5% tint
  - level 4: 8dp + 8% tint
  - level 5: 12dp + 11% tint
- **FAB** 单独用 6dp elevation + 阴影
- **对话框**用 3dp elevation

### 5.7 动效(克制)
- **曲线**: Material 3 Emphasized(进入)/ Standard(退出)
- **时长**:
  - 微交互(按钮): 100ms
  - 状态切换: 200ms
  - 页面切换: 300ms
  - 模态弹出: 400ms
  - 庆祝动画: 2000ms
- **缓动**: `FastOutSlowInEasing`(Material 3 标准)
- **不做的动效**:
  - ❌ 粒子效果
  - ❌ 复杂过场
  - ❌ 骨架屏(直接显示内容)
  - ❌ Loading 旋转(本地操作无需)

### 5.8 图标
- **风格**: Material Symbols Rounded(Google 开源)
- **尺寸**: 20dp(行内)/ 24dp(标准)/ 32dp(大图标)
- **颜色**: 跟随 onSurface / primary
- **风格变体**: 默认 Outlined,选中 Filled

### 5.9 插画
- 几乎不用插画
- 仅在空状态用 1-2 张极简线稿(如"还没记录"时显示一支枯笔)
- 全部为内置 SVG,无网络依赖

## 6. 交互规范(Google Material 3 标准)

### 6.1 导航结构
**底部 NavigationBar + 5 Tab + 中央 FAB**:
```
┌─────────────────────────────┐
│ 顶栏(AppBar 或搜索框)         │
├─────────────────────────────┤
│                             │
│     主内容区(NavHost)          │
│                             │
│                             │
├─────────────────────────────┤
│ 🏠  📈  🌱  📊  ⚙️   [+FAB]  │
│ 主页 技能 目标 报告 我的  记录│
└─────────────────────────────┘
```

### 6.2 核心手势(标准 Android)
| 手势 | 触发 | 效果 |
|---|---|---|
| 单击主 FAB | 中央 | 调起"开始记录"模态 |
| 单击技能卡片 | 技能页 | 进入技能详情 |
| 长按技能卡片 | 技能页 | 显示快捷菜单(开始/编辑/归档) |
| 左滑 Tab | 任意 Tab | 切换到下一个 Tab(材料设计可选) |
| 下拉刷新 | 列表 | 重新计算本地数据 |
| 上滑 | 长列表 | 滚动 |
| 双指捏合 | 统计图 | (可选)切换时间维度 |

### 6.3 FAB(浮动操作按钮)
- **位置**: 底部导航栏右侧,稍高出导航栏 16dp
- **形状**: Material 3 ExtendedFAB(宽形,带文字)
- **文字**: "开始记录" / 计时中显示"暂停"/"继续"
- **颜色**: primary 容器(浅青底)
- **状态**: 滚动时缩小为普通 FAB,顶部时恢复

### 6.4 模态(ModalBottomSheet)
所有"选择/输入"操作都用 **ModalBottomSheet** 而非 AlertDialog:
- 技能选择
- 分类选择
- 标签输入
- 备份/恢复
- 设置项选择(主题/默认技能)
- 提示确认

**好处**: 不打断上下文,符合 Material 3 现代规范。

### 6.5 反馈机制
| 类型 | 工具 | 时长 | 示例 |
|---|---|---|---|
| 视觉 | 颜色/形状变化 | 即时 | 按钮按下变深 |
| 触觉 | HapticFeedback | 50ms | 主操作触发 |
| 短反馈 | Snackbar | 4 秒 | "已保存"/"已删除,可撤销" |
| 中反馈 | Toast(慎用) | 2 秒 | 仅"导出成功"等 |
| 长反馈 | ModalBottomSheet | 用户主动关 | 错误说明 |

### 6.6 错误处理(零中断)
- **不弹错误**(Snackbar/Toast 即可)
- **自动重试**: 3 次静默重试
- **降级显示**: 数据计算失败时显示原始数据
- **绝不弹** "网络错误" "未知异常" "请稍后重试" — 这种 App 没有"网络错误"

### 6.7 空状态(零评判)
| 场景 | 文案 |
|---|---|
| 今日无记录 | "今日。还没开始。" |
| 技能列表空 | "还没有技能。在'开始记录'里添加一个。" |
| 报告无数据 | "此刻,还无数据。" |
| 搜索无结果 | "未找到匹配的记录。" |

**原则**: 平静、简短、不催促、不评判。

### 6.8 无障碍(Material 3 标准)
- 所有元素 `contentDescription` 中文
- 字号支持系统缩放(SP 单位)
- 颜色对比度 ≥ 4.5:1
- TalkBack 焦点与视觉一致
- 主按钮支持键盘焦点
